## 📖 项目简介

**TCM-Research** 是一个系统化梳理中医药理论体系、经典医籍正本对照、辨证论治逻辑数字化建模及现代中医药理循证的开源学术研究知识库。

本项目旨在：
1. **溯源经典**：以权威学术底本为真源，系统研读《黄帝内经》《伤寒论》《金匮要略》《神农本草经》等经典文献。
2. **理法方药**：建立病机辨析、八纲/六经/脏腑辨证到经方加减的结构化知识网络。
3. **现代循证**：连接现代中医药理学、植物化学成分与循证医学研究。
4. **数智辅助**：探索知识图谱、自然语言处理等技术在中医古籍文献整理中的工程化实践。
